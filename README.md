# MathSpring

Initial Flutter project for an olympiad math learning app targeting iPhone and
iPad with a shared adaptive codebase.

Current product direction:

- Modern minimalist visual system with deep-blue branding
- Adaptive layout for iPhone and iPad
- System-locale default with manual language switching
- Initial interface and content support for Traditional Chinese and English
- Data model prepared for later Simplified Chinese and Japanese expansion
