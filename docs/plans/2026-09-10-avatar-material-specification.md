# 紙娃娃素材規格（內部）

本文件是紙娃娃圖片、圖層與驗收的共同語言；不會顯示在 App 介面。目的不是限制髮型只能長成同一個樣子，而是讓新增或修改素材時，能明確知道每張圖的角色、可變動的範圍與檢查方式。

## 編號原則

- ID 格式固定為 `{girl|boy}_{part}_{nn}`；一旦釋出，不因美術改圖而改號或重複使用。
- `01` 是各部位的預設版本。`girl_face_01 + girl_hair_01`、`boy_face_01 + boy_hair_01` 是人工檢視髮型時的基準組合。
- 基準是視覺邊界，不是把每一張髮型硬對齊到同一個座標：髮量可往頭外發展，但往臉內延伸時不得造成額頭、眼睛、兩頰或下巴明顯被遮住，也不得留下髮際與臉之間的不自然空隙。
- 初版不設定數字座標或像素界線。每次換圖以實際合成截圖人工核對；視覺穩定後，才另補標準化座標資料。

## 圖層規則

- `skin` 只含皮膚色像素；透明區必須保持透明，不能把底色或背景一併染色。
- `face` 是臉部輪廓與底圖；眼睛、鼻子、嘴巴是獨立細節層。
- `hair` 可有前、後兩層：後層只能在頭部／臉後方可見，前層不可壓住眼睛與大面積臉部。
- 眼鏡不再是獨立疊加層。帶眼鏡的素材是含正常眼睛的完整 `eyes` 圖；瞳孔、眼白必須位於鏡片／鏡框的合理範圍內。

## 人工截圖驗收

每一張新增、替換或調整過的素材，都要輸出完整紙娃娃合成圖並保留截圖。最低檢查組合如下：

1. 基準組合：`face_01 + hair_01`。
2. 每一款髮型：分別搭配 `face_01`；查看髮際空隙、額頭、雙眼、兩頰與下巴。
3. 每一款眼部素材：搭配 `face_01` 與預設膚色；眼鏡款另確認雙眼仍在鏡片範圍。
4. 每一款膚色：搭配預設臉與髮；確認透明背景、頭髮、五官都沒有被膚色濾鏡改變。

任何一項出現「髮型蓋眼太多、臉邊留空、眼睛跑出鏡框、背景變色、或和相鄰選項太像」即不通過，先替換或刪除素材，再重新截圖。

## 素材變更紀錄欄位

未來每次改素材時，在變更紀錄附上：`ID`、一句視覺敘述、是否前／後層、基準臉截圖位置、人工檢查日期與結果。如此同一個編號永遠可追溯，也能在之後真的需要時再加入數字化的位置規則。
