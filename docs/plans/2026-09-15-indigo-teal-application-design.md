# 深靛藍與青綠全站視覺系統

## 色彩角色

- 深靛藍是品牌及主要操作色：主要按鈕、目前導覽、頁面標題重點、重要連結。
- 青綠是學習進展色：答對、完成、進度、已選項、已收藏與正向提示。
- 暖白是主要畫布，石墨灰是文字，淡靛灰只用於邊框與次要背景。危險操作維持低彩度紅。

## 全站元件規則

- 所有頁面套用同一套畫布、文字與 Material component theme，清除散落的海軍藍、純藍和不一致灰色。
- 卡片、選項、輸入框與彈窗皆用 14px 圓角、細邊框和極淺陰影；主內容優先，裝飾與色彩只服務狀態和操作。
- 主按鈕使用深靛藍實心，次要按鈕與工具按鈕使用外框；青綠只用於完成或選取後的正向回饋，不與主操作競爭。

## 頁面套用

- 首頁、練習、測驗、學習回顧、帳號設定、收藏、紙娃娃編輯器與結果頁都使用同一套 token。
- 答題題幹、收藏題幹、學習紀錄為第一視覺層；年級、主題、時間、標籤等屬第二層。
- 需在窄螢幕、iPad 與 macOS 進行視覺檢查，確認主要 CTA、底部導覽、題目選項及清單沒有擁擠或跑版。
