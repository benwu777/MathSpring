# 男生髮型 2、3 初稿設計

## 範圍

本輪只重製男生紙娃娃髮型 2、3 的造型；髮色暫不作為選項差異，後續統一採用與女生相同的可調色機制。

## 視覺方向

- **髮型 2**：自然短碎髮。頂部與兩側有輕微向上的髮束，輪廓俐落但不做尖刺誇張造型。
- **髮型 3**：側分中短髮。明確分線，瀏海順著一側自然垂落，兩側在太陽穴收束。

兩款均以目前合格的髮型 1、6 為品質與尺寸基準：平塗插畫、細線稿、深棕黑中性底色與柔和高光；造型須與 1、6 一眼可辨。

## 圖層契約與驗收

輸出為 `assets/avatars/boy/hair/hair-02.png`、`hair-03.png`，各為 1254×1254 sRGB PNG 且帶 alpha。髮型僅包含髮部，保留透明畫布與絕對對位；不得出現臉、五官、背景、文字或浮水印。佔位遵循男生髮型的 x 172–1112、y 159–905；瀏海最低點不得低於 y=490，以確保眉眼可見。

產生後須去背、檢查 alpha 與綠邊，並於 MathSpringReviewer 的「紙娃娃素材檢視」中，和髮型 1、6 並列確認冠部大小、五官可見性及縮圖與大預覽的一致性。
