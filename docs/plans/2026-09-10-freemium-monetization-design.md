## 一、一句話總結

**免費層是一本完整可用的 3,141 題題本；付費買的是「看得懂為什麼」。**

收費收在對手做不到的東西上（100% 附詳解），而不是收在「不准你練」。

## 二、分類與分級

| 項目 | 決定 |
| --- | --- |
| App Store 分類 | **Education（教育）** |
| 年齡分級 | **4+** |
| Kids Category | **不進** |
| 版本數 | **只有一個 app、一份 build**，不做 flavor、不做第二個 bundle ID |

**不進 Kids Category 的理由**：Kids Category 受審核指南 1.3 約束——不得有行為式廣告、
情境廣告須適合兒童、不得將裝置資訊傳給第三方，實務上等於「放了廣告但賺更少，還多一層退件風險」。
兒童專區的曝光紅利對一個沒有行銷預算的新 app 幫助有限，Education 分類 ＋ 4+ 分級已足夠讓家長找到。

**不切學校版的理由**：Oddrobo 的「數學之王：學校版」之所以要獨立上架，是因為學校透過
Apple School Manager 大量採購時**買得到 app、買不到 IAP**，而他們的免費版鎖住了內容。
我們的免費版所有題目都能作答，學校直接用免費版即可，獨立付費 app 沒有價值主張。
（唯一伏筆：學校裝置通常不接受廣告。真有學校來問時再開 build flavor，約一天工。）

## 三、免費層 —— 完整可用，不是試用版

- **全部 3,141 題（grade1–grade12）都能作答，沒有任何每日額度**
- 作答後顯示 **對／錯 ＋ 正確答案**
- 每日五題任務照舊（維持 `DailyMission.targetCount = 5` 原本的「目標」語意，**不是上限**）
- 正式測驗全開，含現有的 5 題/10 分、10 題/20 分、15 題/30 分限時方案
- 學習回顧全開（概念弱點分析）
- **1 個**學習者角色
- 底部常駐 banner 廣告

### 為什麼沒有每日額度

過程中評估過三種額度設計，全部否決：

| 方案 | 否決原因 |
| --- | --- |
| 每天 N 題練習 | 使用者會在練習中途被攔下，挫折感最高；且正式測驗無次數限制，會成為繞過額度的後門 |
| 按年級切片（低年級免費） | 砍掉漏斗頂端——八年級生下載後發現只有小一到小三能用，直接刪除 |
| 按難度切片（基礎免費、進階付費） | **資料上做不到**：全庫 3,141 題 100% 是 `foundation`，難度維度是平的 |

取消額度的連帶好處：**所有繞過問題一併消失**（角色數、刪除角色刷額度、日期回調、重裝重置）。
在沒有伺服器的前提下，那些防線本來就是漏的。

### 為什麼免費層要這麼大方

廣告收入完全取決於使用者留著 app、每天打開。任何形式的每日額度都在壓抑留存，
也就是在壓抑廣告收入。無限免費練習 = 最高留存 = 最多曝光。

## 四、付費層 —— NT$60（US$1.99）一次性解鎖

**商品型態**：Non-Consumable IAP（非消耗型），**非訂閱**，綁 Apple ID，
必須提供「回復購買（Restore Purchases）」按鈕（Apple 強制要求）。

**價格說明**：US$2.00 不是 Apple 的標準價格級距，最接近的是 **US$1.99**，台灣約 NT$60。
這個價位與直接競品「數學之王」的 IAP「完整版 NT$60」及其學校版售價完全一致。

解鎖後得到四樣東西：

| # | 內容 | 性質 |
| --- | --- | --- |
| 1 | **完整詳解** —— 3,141 題全部的 `solutionSteps` | 主功能 |
| 2 | **移除廣告** | 體驗 |
| 3 | **紙娃娃全套樣式**（髮型、膚色、眼色、眼鏡） | 外觀 |
| 4 | **最多 5 個學習者角色** | 家庭需求 |

四項各佔一個維度（主功能／體驗／外觀／家庭），組合完整、好賣。

**角色上限的定位已改變**：原本「免費 1 個」是為了防止建新角色刷每日額度；
現在沒有額度了，它純粹是付費特典。若日後覺得限制家庭使用不妥，拿掉不影響任何其他設計。

## 五、廣告

| 項目 | 決定 |
| --- | --- |
| 形式 | **只放底部常駐 banner** |
| 不做 | 插頁（interstitial）、獎勵式影片（rewarded） |
| 例外 | **正式測驗作答中不顯示 banner**，避免干擾限時作答 |
| 已購買者 | 完全隱藏 banner |

### 已知且已接受的取捨

只放 banner 是明確的取捨，不是疏漏。舊評估文件曾建議「務必包含插頁，否則收入模型不成立」，
這個建議在**收入最大化**的前提下是對的，但已被否決，理由是這是給小孩用的 app，
不希望學習流程被全螢幕廣告打斷。

**因此廣告收入在初期應視為零，US$1.99 的解鎖承擔幾乎全部收入。**

### 留存是廣告收入的唯一變數

banner-only 的收入完全取決於使用者是否每天打開 app。
**每日練習提醒**（本地通知，不需伺服器）是提升留存最直接、成本最低的手段，
可行性已確認，見 `docs/daily-reminder-handoff.md`。建議放在免費層而非付費特典。

### 版面影響（實作時要算進去）

版面前陣子才改成滿版（`LayoutSpec` 依寬度分級、`fill` 模式捲動殼、iPad 專屬版面）。
**底部常駐 banner 會吃掉一條固定高度**，這些版面都要重新留出空間，iPad 上尤其明顯。

## 六、paywall 出現時機

- **主要觸發點**：使用者點詳解區塊時跳出解鎖畫面
- **常駐入口**：設定頁固定一列「解鎖完整版」
- **除此之外不主動打擾**：不做「剩 N 次」倒數提示，不在 banner 旁加可點擊元素
  （AdMob 對 banner 周圍的可點擊元素有規範，容易誤觸違規）

---

## 七、已知風險

**1. 全部付費理由押在詳解品質上。**
這是本設計最大的單點風險。2026-09-10 使用者隨手抽查的第一題
`arithmetic_grade4_foundation_066` 詳解就是壞的——答案對、公式對，但敘述邏輯不通
（異單位相加、中間值語意前後矛盾）。3,141 篇詳解目前只過了工具閘門，沒有被逐篇讀過。
**上架前必須完成詳解品質流程**，見 `docs/solution-quality-review-process.md`。

**2. 免費體驗可能過於單薄。**
小孩答錯時只看到「答案是 288」，是最需要幫助卻幫不上忙的一刻。
緩解方案（尚未採用）：把 `solutionSteps` 的第一句放出來當提示，完整步驟仍付費。
實作上只是渲染陣列時切一刀，隨時可加。

**3. 沒有伺服器。**
沒有跨裝置同步，換手機資料就沒了。這對已付費的家長是實際痛點，屬架構層級限制。

## 附錄：廣告收入的量級參考（自舊評估文件保留）

廣告收入 = 曝光數 × eCPM ÷ 1000。要達到 Apple 每年 99 美元開發者年費：

| eCPM 情境 | 一年需要的曝光數 | 換算成穩定 DAU |
| --- | --- | --- |
| $0.30（悲觀：非個人化 ＋ 台灣流量） | 333,000 | 約 114 |
| $0.60（中性） | 167,000 | 約 57 |
| $1.00（樂觀：banner 上限） | 100,000 | 約 34 |

DAU 換算假設：每人每天 1 次練習、單一 banner 每 30–60 秒刷新、一次 session 約 8 次曝光。
穩定維持 57 DAU 大約需要累積 2,000–5,000 次下載。

**AdMob 撥款門檻是 US$100，掛在「帳號」而非「app」層級**——同一個 AdMob 帳號底下所有 app
（含 iOS 與 Android）收益合併計算，且**收益不會過期，逐月累加結轉**。
另有一道 US$20 的地址驗證門檻（Google 寄 PIN 到填寫地址），累積到就要盡快完成，否則會卡住。

估算限制：eCPM 受地區、季節、競價影響；DAU 換算假設每人每天一次 session，
實際使用頻率可能更低；未計入年費以外成本；AdMob 收益屬海外所得，稅務不在本文範圍。
