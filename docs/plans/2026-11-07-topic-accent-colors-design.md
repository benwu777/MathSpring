# 主題色設計（2026-11-07）

## 決定

- 範圍：App 介面，不動題目附圖。
- 整體配色不動（米白底、白卡片、靛藍主色、按鈕、答對答錯色、底部導覽）；分頁與狀態色維持統一。
- 數學主題各配一色，只用在小地方：卡片左側細色條、主題標籤的文字與外框、主題徽章的細框與圖示。
- 色調採「沉穩學術色」（使用者看過 A／B 兩組樣張後選 A）：

| 主題 | topicCode | 色碼 | 白底文字對比度 |
| --- | --- | --- | --- |
| 幾何 | geometry | #1F5FBF | 6.1 : 1 |
| 算術 | arithmetic | #1E7F4F | 5.0 : 1 |
| 代數 | algebra | #B0306A | 6.0 : 1 |
| 邏輯 | logic | #A86200 | 4.8 : 1 |
| 組合 | combinatorics | #6B3FB3 | 7.0 : 1 |
| 數論 | number_theory | #0E7C86 | 4.9 : 1 |
| 綜合 | mixed | #4A5D7A | 6.7 : 1 |

查不到的主題退回綜合色。

## 套用位置（目前畫面上有顯示主題名稱的四處）

1. 題庫頁的題組卡片：左側 5 px 主題色條；主題標籤改主題色外框與文字。
2. 題庫頁的作答紀錄卡片：左側主題色條；主題名稱改成主題色標籤。
3. 紀錄分頁的主題里程碑徽章：白底、主題色細框與圖示；連續天數、訂正徽章不變。
4. 首頁「已選主題」：左側主題色條；主題名稱改主題色。

## 驗證

- 單元測試：七主題都有顏色、未知主題退回綜合色、每色在白底的對比度 ≥ 4.5 : 1（改得太淡會被擋）。
- Widget 測試：四處各自用到對應主題色；按鈕與底色不變。
- 在 iPhone 模擬器截圖改版前後的完整畫面給使用者確認；深色模式與放大字級各看一次。
