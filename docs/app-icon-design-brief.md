# MathSpring App 圖示設計簡報（2026-11-01 第三版）

第一版找錯競品、方向是預設答案；第二版把參考 app 當成範本（「向 Euclidea × 紀念碑谷看齊」），等於模仿，且重複前幾輪被否決的元素。兩版都已作廢。
參考研究的用途只有一個：確認哪些路已經被走過、要避開。概念一律從 MathSpring 自己發展。

## 1. 產品定位（取自 `docs/initial-product-outline.md` 與 App Store 文案）

- 給準備數學競賽、喜歡思考挑戰的孩子，以及替他們挑選 app 的家長；同一台裝置可多位兄弟姊妹共用。
- 調性：**沉穩、精準、有質感（calm, precise, premium）**，**不像兒童玩具**。
- App Store 副標題：「離線數學練習與思考挑戰」。

## 2. 圖示要達成的三件事（使用者訂）

1. **精緻、美的設計感**。
2. **呈現數學的本質**——結構、對稱、比例、規律、構造與證明，不是 + − × ÷、數字或座標軸這些表面符號。
3. 第一眼讓人**想進去體驗**。

## 3. 參考研究（App Store 實際圖示，名稱已核對）

| 類別 | App | 觀察 |
| --- | --- | --- |
| 思維類競品 | 火花思維、斑馬思維、豌豆思維、DragonBox、Think!Think!、學而思、Brilliant | 前五個是高飽和卡通吉祥物或數字，鎖定學齡前到低年級；Brilliant 用柔和漸層的抽象 3D 造型，是這類裡最精緻的 |
| 學習平台 | Khan Academy、Photomath、Prodigy | 純色平塗加單一記號：乾淨、可信，但像工具，談不上美；Khan 的「葉子」已占用「成長」意象 |
| 數學美學 | Euclidea、Desmos、GeoGebra | **Euclidea**：真實質感的圓規在藍圖上作圖，呈現「推理與構造」，最接近「數學本質＋精緻」；Desmos、GeoGebra 是平塗的數學內容，沒有情感 |
| 空間美學 | 紀念碑谷、紀念碑谷 2、Alto | 圖示是**一個可以走進去的空間**：等角幾何建築、小人物帶出尺度、前中後景與光源——這是「想進去體驗」的來源 |
| 思考遊戲 | Brain It On、Elevate | 一個物理機關或大腦圖，偏遊戲或腦力訓練 |

結論：

- 「美」來自**光影、漸層、層次與克制的配色**（兩到三個色相）；純色平塗只會像工具。
- 「數學本質」：多數競品停在運算符號或數字；要呈現的是數學的**結構與規律**本身。
- 「想進去」來自**空間感**：深度、透視、光源，讓人想看清楚裡面。
- 以上只是原則；具體造型不得取自任何參考 app（見第 5 節）。

## 4. 概念來源：名字的本意

**MathSpring 的 Spring＝泉水、源泉**（使用者確認）：數學思維的源頭，想法從這裡湧出、源源不絕。
圖示從「泉」發展，並以數學本身的結構表現（例如無窮、收斂、對稱、比例、規律），讓「泉」同時就是數學。

**泉水要搭配一個看得見的數學符號**（使用者 2026-11-01 確認）：只把數學藏在比例或間距裡，看的人讀不出來。
符號本身是主體，佔滿畫面，用水的質感畫出來；符號選有「源頭、不絕、累積」意義的（√、∞、Σ），不用 + − × ÷ 與數字。

## 5. 已被占用、要避開的意象

| 意象 | 已被誰使用 |
| --- | --- |
| 葉子／嫩芽（成長） | Khan Academy |
| 尺規作圖、圓規 | Euclidea |
| 等角幾何建築、小人物站在台座上 | 紀念碑谷 |
| 函數圖形、座標軸 | Desmos、GeoGebra |
| 大腦、燈泡 | Peak、Elevate |
| 卡通吉祥物 | 火花、斑馬、豌豆、DragonBox |
| + − × ÷、數字格 | 算術與數獨類 |
| 黃金螺線、費氏方格 | 太常見，且前幾輪已被否決 |

## 6. 限制

- Apple 規範：1024×1024、不透明、不自己畫圓角、不放文字。
- 60pt 桌面大小仍要看得出主結構：空間感來自少數大塊面與一個光源，不靠細節堆疊。
- 深色、染色模式下主結構仍成立。

## 7. 成功標準

1. 和上表參考圖示並排時，質感不輸最精緻的那幾個，但長相明顯不同、不會被認成任何一個的翻版。
2. 看到的人說得出「這是數學」，但不是因為看到 + − × ÷ 或數字。
3. 畫面有深度與光源，會讓人想知道「裡面是什麼」。
4. 每個造型、顏色都說得出對應的數學概念或理由。
