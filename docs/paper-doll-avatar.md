# 紙娃娃 Avatar 規格

## 目的

紙娃娃讓使用者依序選擇性別呈現、膚色、臉型、髮型、眼睛、鼻子與嘴巴。所有選項必須可以點擊、立即反映於上方預覽，且男女每個部位至少提供五個選項。

## 目前選項數量

| 部位 | 女生 | 男生 |
| --- | ---: | ---: |
| 膚色 | 5 | 5 |
| 臉型 | 5 | 5 |
| 髮型 | 5 | 5 |
| 眼睛 | 5 | 5 |
| 鼻子 | 5 | 5 |
| 嘴巴 | 7 | 5 |

除了男生髮型，每個選項都有自己的圖層檔案。實體圖層張數：

| 部位 | 女生 | 男生 |
| --- | ---: | ---: |
| 臉型 | 5 | 5 |
| 髮型 | 5 | **2** |
| 眼睛 | 5 | 5 |
| 鼻子 | 5 | 5 |
| 嘴巴 | 7 | 5 |

膚色是對所選臉型圖層疊色，不需要獨立素材。男生髮型是唯一還在用共用圖層頂替的部位
（第三、四款鏡像，第五款縮小），補素材的規格見 `docs/avatar-asset-generation-rules.md`。

## 圖層與畫布規則

每張可疊加的 PNG 使用同尺寸正方形透明畫布；不可將單一五官裁成只有五官本體後直接取代圖層，否則會失去共同座標，造成五官漂移。

預覽由下到上固定為：

1. 基底臉／膚色
2. 眼睛
3. 鼻子
4. 嘴巴
5. 頭髮

頭髮必須最後繪製，讓瀏海可以自然蓋在額頭上；眼睛、鼻子與嘴巴不得被頭髮以外的透明底色覆蓋。

## 臉部對位規則

- 眼睛：同一組左右眼維持固定中心距，女生眼睛額外縮為 `0.92x`，使兩眼略向內靠。
- 鼻子：固定於眼睛下方；鼻子造型可改變，但不得改變其臉部錨點。
- 嘴巴：以自然笑臉的寬度作為上限，可縮小或改嘴型，不得任意降低到下巴區域。
- 男生基準定位：鼻子 `0.092`、嘴巴 `0.168`。選「小鼻子」（`boy_nose_02`）時，嘴巴改為 `0.20`，僅作微幅避讓；禁止使用較大的 `0.24` 位移。
- 女生基準定位：鼻子 `0.10`、嘴巴 `0.08`。

新增五官素材前，需在男女基準臉、不同髮型與至少一種非預設膚色下確認：眼、鼻、嘴相對位置仍自然，且五官不互相重疊。

## 膚色與鼻子規則

膚色不是只改基底。當選擇非預設膚色時，鼻子必須套用相同的色相與明暗處理；否則會出現深色皮膚搭配過淺鼻子的斷裂感。

- `*_skin_01`：預設原始基底色。
- `*_skin_02`：較深、暖棕色調。
- `*_skin_03`：另一個較飽和的暖棕色調。
- `*_skin_04`：較淺的蜜糖色。
- `*_skin_05`：最深的可可色。

目前以透明色調處理維持現有插畫筆觸。若之後改用實體膚色素材，鼻子也必須提供對應膚色版本，或保留同等效果的動態調色。

## 新造型怎麼來

新選項一律**從既有已驗收的圖層局部變形衍生**，不重新生一張：畫風一致，而且來源已經
對好位，形狀改了也不會漂移。規則與控制點寫在 `scripts/derive_avatar_layers.py`，
重跑 `python3 scripts/derive_avatar_layers.py` 就能重建全部衍生圖層。

腳本遵守的原則：

- 畫布維持 1254×1254 透明，不裁切、不縮放。
- 用 anchor 釘住不該動的地方：頭頂、臉型變形時的眼睛帶、眼型變形時的眉毛與兩眼中心
  （所以左右眼距永遠不變）。
- 一個 preset 只動一個部位。
- 位移是形狀改變（下顎寬窄、眼皮弧度、鼻翼開合、嘴角高低），不是等比縮放——
  等比縮放正是這些圖層要取代的東西。

目前衍生出來的造型：

| 部位 | 造型 |
| --- | --- |
| 臉型 | 原型、窄長臉、寬圓臉、方下顎、尖下巴 |
| 眼睛（女） | 原型、既有第二款、圓大眼、細長眼、上揚眼 |
| 眼睛（男） | 原型、圓大眼、細長眼、上揚眼、下垂眼 |
| 鼻子 | 原型、既有第二款、寬鼻翼、長鼻樑、小巧上翹 |
| 嘴巴（男） | 原型、既有露齒笑、大笑、抿嘴、上揚微笑 |

膚色仍是疊色，四種色調（深棕、暖棕、蜜糖、可可），鼻子同步調色。

男生髮型還沒有素材，暫時第三款鏡像第一款、第四款鏡像第二款、第五款縮為 `.92`
並下移 `.02`（露耳短髮）。這是唯一保留的頂替，補素材後要一併移除。

臉型不可用加寬冒充：女生超過 `1.10x` 臉頰會露到髮線外，所以臉型一律走實體圖層。
## 新增素材的驗收清單

- 保持正方形、透明、與同類圖層一致的畫布尺寸。
- 髮型可向上、左、右延伸，但瀏海不可大量遮住眼睛、鼻子或嘴巴。
- 眼睛可以改大小與形狀，但左右中心距要與基準一致。
- 鼻子維持固定占位大小範圍，僅調整形狀；膚色需同步。
- 嘴巴以笑臉最大寬度為上限；不同嘴型必須可一眼區分。
- 不接受帶有 X、棋盤格、純色背景、色邊、殘留文字或不透明方塊的素材。
- 生圖若帶去背色，用 `scripts/remove_chroma_key.py <chroma.png> <out.png>` 去背；它會把綠色溢色壓回紅藍水準，避免髮絲邊緣殘留綠邊，處理後需確認整張圖 `G - max(R, B) <= 0`。
- 將素材加入選單前，確認檔案存在、縮圖無破圖、點選後預覽有差異。

## 實作位置與測試

- 選項清單：`lib/models/avatar_configuration.dart`
- 素材、共用圖層對應與比例／位置規則：`lib/services/avatar_asset_catalog.dart`
- 疊圖預覽：`lib/widgets/avatar_preview.dart`
- 選項格與縮圖處理：`lib/widgets/avatar_editor.dart`
- 素材衍生：`scripts/derive_avatar_layers.py`；生圖規則：`docs/avatar-asset-generation-rules.md`
- 驗證：`test/avatar_catalog_test.dart`、`test/avatar_preview_test.dart`、`test/avatar_editor_test.dart`

每次調整物件規則後，執行：

```sh
flutter test test/avatar_catalog_test.dart test/avatar_preview_test.dart test/avatar_editor_test.dart
```
