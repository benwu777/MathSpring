# App Store 截圖計畫

截圖必須來自已編譯的實際 app，不可使用設計稿或後製畫面。首發支援 iPhone 與 iPad，繁中與英文各準備一組。

## 取得前準備

1. 用乾淨的 Simulator 資料啟動 app，建立可重現的示範學習者與練習紀錄。
2. 分別將 app 介面設為繁中與英文；題目內容必須與選定語系一致。
3. 使用最新可用的 iPhone Pro Max 與 iPad Pro Simulator，保留裝置原生解析度，勿加裝置外框或文字覆蓋。
4. 建議輸出位置：`release-assets/app-store-screenshots/<locale>/<device>/`。此資料夾是發布素材，不納入 app source。

## 每個語系的五個畫面

| 編號 | 畫面 | 重點 |
| --- | --- | --- |
| 01 | 首頁／學習者 | 呈現可建立或選擇學習者的起點。 |
| 02 | 年級或程度選擇 | 顯示學習範圍與清楚的開始動作。 |
| 03 | 主題／題組選擇 | 呈現數學主題與題組資訊。 |
| 04 | 正在作答 | 使用真實題目、圖形或選項，且不要顯示測試資料。 |
| 05 | 結果或歷史紀錄 | 呈現作答回饋、解法或可回顧的歷史。 |

## 驗收

- [ ] iPhone 與 iPad 都有繁中、英文截圖。
- [ ] 每張畫面沒有 placeholder、debug banner、通知或模擬器外框。
- [ ] 文字不截斷、按鈕不重疊，且題目與選項可閱讀。
- [ ] 截圖順序能說明完整使用流程，而非只重複首頁。
- [ ] 上傳前依 App Store Connect 當時顯示的尺寸／裝置要求確認檔案。
